## ExoHub provides a unified framework for managing distributed data across hybrid-cloud environments.

Treat your data with the same rigor as source code using git-annex foundations and modern orchestration.

### Core Components

- **[ExoGit](/docs/components/exogit/)**: Git-based data repository management with version-controlled pointers
- **[ExoCLI](/docs/components/exocli/)**: Opinionated git-annex interface for simplified data operations
- **ExoWorkers**: Resilient orchestration engine for automated workflows
- **ExoGate**: On-premises gateway bridging cloud and local resources
